Lab 3: JSON

Exercise 2: Create and Validate JSON

Part A: Message JSON

{
  "to": "Alex",
  "from": "Jordan",
  "heading": "Reminder",
  "body": "Don't forget our meeting tomorrow."
}

Part B: Book Collection JSON

{
  "books": [
    {"title":"Web Development Basics","author":"Maya Lee","price":29.99},
    {"title":"Modern JavaScript","author":"Daniel Kim","price":34.50},
    {"title":"Understanding JSON","author":"Sofia Patel","price":24.95}
  ]
}

Both JSON examples use valid JSON syntax: quoted property names, quoted text values, numeric prices, arrays, objects, and correctly placed commas.
