Lab 3: JSON

Exercise 1: Explore and Understand JSON Structure

The Open Library book JSON is a JSON object containing name/value pairs. The example below is based on the Open Library record for Fantastic Mr. Fox.

Name/Value Pair

"title": "Fantastic Mr. Fox"

Object

"type": {
  "key": "/type/edition"
}

Array

"publishers": ["Puffin"]

Nested Structure

"authors": [
  { "key": "/authors/OL34184A" }
]

Overall, the record is organized as one main object containing simple values, arrays, and nested objects. Arrays are used for collections such as authors, publishers, covers, languages, and identifiers.
